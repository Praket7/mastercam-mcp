# Product walkthrough video

This short animation shows a sample data review. It is an illustration of the current workflow. It is not a screen recording from Mastercam. Its parameter change is synthetic.

The counts shown come from source checks. The tool count is the current registered MCP catalog. The vendor record count is from one imported ISO 13399 feed. These figures do not measure saved machining time. They do not measure tool coverage across brands. They do not prove live Mastercam acceptance.

To render this video, install Node.js 22+. Run `npm install`. Run `npm run render`. The source composition is in `src/video.jsx`. The generated image is in `public/workflow_illustration.png`.
